# Panduan Memproses Pesanan

<PageDate />

Halaman ini menjelaskan tata cara cara memproses pesanan hingga selesai.


### 1. Masuk Ke Halaman Seller
Pada halaman dasboard pilih login sebagai **Penjual**
![Klik Penjual](/images/pesanan/2.png)

### 2. Masukkan Email dan Password 
- Pada halaman dasboard penjual, isikan email dan password yang terdaftar.
- Klik tombol Masuk
![Klik Masuk](/images/pesanan/3.png)

### 3. Masuk Ke Halaman Pesanan
- Pada halaman dasboard penjual, pilih menu Pesanan.
- Klik Daftar Pesanan
![Klik daftar pesanan](/images/pesanan/4.png)

### 4. Masuk Ke Halaman Detail Pesanan
- Pada halaman Daftar Pesanan, pilih pesanan yang akan diproses dengan status (siap diproses)
- Klik tanda titik "..." (detail pesanan).
![Klik detail pesanan](/images/pesanan/5.png)

### 5. Menerima Pesanan
- Pada halaman Detail Pesanan, klik tombol Terima Pesanan untuk melanjutkan proses pesanan
![Klik terima pesanan](/images/pesanan/6.png)

### 6. Mengkonfirmasi Pesanan
- Pada halaman Detail Pesanan, muncul informasi untuk konfirmasi pesanan.
- Isikan Estimasi Pengiriman.
- Klik tombol Proses
![Klik tombol proses](/images/pesanan/7ref.png)

### 7. Melanjutkan Pesanan
- Setelah klik tombol Proses, muncul peringatan untuk melanjutkan pesanan atau tidak.
- Klik tombol Lanjutkan
![Klik tombol lanjutkan](/images/pesanan/8.png)

### 8. Mengirim Pesanan
- Pada halaman Detail Pesanan, klik tombol Kirim Pesanan untuk melanjutkan proses pesanan
![Klik kirim pesanan](/images/pesanan/9.png)

### 9. Konfirmasi Pengiriman
- Pada halaman Detail Pesanan, muncul informasi untuk konfirmasi Pengiriman.
- Isikan Nomor Resi (Opsional).
- Klik tombol Simpan
![Klik tombol simpan](/images/pesanan/10.png)

### 10. Melanjutkan Pengiriman Pesanan
- Setelah klik tombol Simpan, muncul peringatan untuk melanjutkan pesanan atau tidak.
- Klik tombol Lanjutkan
![Klik tombol Lanjutkan](/images/pesanan/11.png)
